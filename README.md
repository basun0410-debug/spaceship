# 🚀 우리 반 우주선 — 임포스터를 찾아라!

전자칠판(선생님 화면) + 학생 패드로 하는 교실용 추리 게임입니다.

- 주소: https://basun0410-debug.github.io/spaceship/
- 전자칠판: 주소 열기 → "선생님 화면으로 시작"
- 패드: 칠판의 QR을 찍거나 주소 열기 → "학생으로 참가하기" → 방 코드 4자리 + 이름
- 최소 4명부터 시작 (혼자 연습할 때는 "🤖 혼자 연습용 로봇 추가")

## 규칙
- 우주선 지도(9개 방)에서 옆 방으로 이동하며 ❗ 방의 수업 퀴즈를 풀어요.
- 임포스터는 같은 방의 크루원을 제거하고, 환풍구·방해 공작(전등/원자로/통신)을 써요.
- 쓰러진 친구를 발견하면 신고, 식당에서는 비상 버튼으로 회의를 열어요.
